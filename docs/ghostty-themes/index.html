Use a theme in Ghostty

In gtheme, press / and enter the name. Press Enter to finish filtering and Enter again to save the highlighted theme. To set it manually, add the theme = … line shown on the card to your Ghostty config and reload.

Theme names and palettes are from Ghostty 1.4.0. Your Ghostty version determines which themes are installed. Ghostty’s color theme guide
