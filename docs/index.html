Install in your home directory

Requires Ghostty on macOS, Python 3.8+, and Git.

git clone https://github.com/hypercryptoman/gtheme.git
cd gtheme
mkdir -p ~/.local/bin
install -m 755 gtheme ~/.local/bin/gtheme
~/.local/bin/gtheme
